# Seeders

## Seed generic placeholder content
Seed only neutral, editable placeholder content. Do not add owner-specific names, contacts, projects, work history, or media to the default database.

## Reset placeholders on reseeding
The development seeders deliberately reset the site settings and sample project image to their generic placeholders. They do not preserve prior seeded content or media.

## Keep default media neutral
PortfolioMediaSeeder installs only the generic profile and project SVG placeholders. The default resume field must remain empty so each owner uploads their own CV through Filament.

## Generic portfolio defaults
Default seeders intentionally reset the portfolio to neutral placeholder content and media. Never add owner-specific profile, contact, project, experience, or CV data to these seeders.
